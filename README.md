# Python Scripting

A collection of small, independent Python utility scripts. Each subdirectory contains one script, along with its own `README.md` describing its specific usage.

## Setup

This project uses [uv](https://docs.astral.sh/uv/) for dependency management.

```powershell
uv sync
```

## Scripts

| Script | Description |
|---|---|
| [directory_sorting](./directory_sorting/) | Sorts files in a directory into subfolders based on file extension |

See each script's own `README.md` for detailed usage instructions.
